# Guardian-QC

<img src="assets/logo.png" width="200" height="227" />

**Notice: This software was developed as a part of a university project and is not currently a fully functioning and tested product. Additionally, ongoing maintenance and contributions to this code by the original developers will cease after 01/04/2027. This application was intended for research and educational purposes. Data Protection of patient sensitive information cannot be assured. User discretion is advised.**

Guardian-QC is a tool that uses unsupervised machine learning to identify quality control outliers from metrics generated by common NGS QC tools, including FastQC, Picard, and bcftools. It was developed for somatic NGS testing, but may be applicable to other sequencing pipelines following appropriate validation.

## Structure of Repositry 
```
guardian_qc/
│
├── main.py                  # entry point, ties everything together
├── app.py                   # if you're building a UI/dashboard layer
├── config.py                # move out of utils — it's top-level config
│
├── data/                    # raw and processed data inputs
│   ├── raw/
│   └── processed/
│
├── pipeline/                # the core ML pipeline stages, in order
│   ├── __init__.py
│   ├── ingest.py            # what you've already built
│   ├── preprocess.py        # ml_data_preprocessing.py lives here
│   ├── train.py             # Isolation Forest fitting per assay/model
│   ├── predict.py           # scoring new runs against trained model
│   └── evaluate.py          # validation metrics, performance checks
│
├── models/                  # serialised trained models (.pkl / .joblib)
│   └── (per assay, per sequencer)
│
├── qc/                      # QC-specific logic
│   ├── __init__.py
│   ├── filter_by_run.py     # filter_by_run_qc.py moved here
│   ├── inter_op.py          # inter_op.py moved here
│   └── thresholds.py        # anomaly score thresholds, flagging logic
│
├── utils/                   # genuinely generic helpers only
│   ├── __init__.py
│   ├── logger.py            # keep here
│   ├── utils_cancer.py      # keep here
│   └── file_io.py           # any file reading/writing helpers
│
├── outputs/
│   ├── graphs/
│   ├── reports/             # add this — for any output summaries
│   └── logs/
│
├── tests/                   # unit tests mirroring pipeline/ structure
│   ├── test_ingest.py
│   ├── test_preprocess.py
│   ├── test_train.py
│   └── test_predict.py
│
└── docs/
```

## Contributing
We welcome contributions to improve Guardian-QC! Here's how you can get involved:

1. **Report Issues**
    - Found a bug or have a suggestion? Open an issue on our GitHub issues page. 
    - Add a label to describe the type of issue, e.g. bug, enhancement.
2. **Submit Changes**
    - Fork the repository and create a new branch for your changes.
    - Make your edits and a thorough suite of tests. Note that we make use of:
      - numpy style docstrings
      - `pylint` or `black` to ensure PEP-8 compliance
      - `coverage` to check test coverage
    - Submit a pull request with a clear description of your changes
